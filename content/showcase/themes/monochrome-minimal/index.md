## Overview

Designed for minimalists and monochrome home screen setups, **Monochrome Minimal OLED** blends seamlessly into the camera cutout with a `#000000` background and subtle `#FFFFFF` / `#A1A1AA` accents.

## Features

- **Zero Color Distraction**: Disables dynamic app color overrides (`use_app_colors: false`) so every notification maintains a cohesive silver-and-white palette.
- **Clean Circular Framing**: Uses `circle` icon masks with `10%` padding for uniform status bar pills.
