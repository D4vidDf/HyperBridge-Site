Setting up Shizuku is completely rootless and takes less than two minutes using Android's built-in **Wireless Debugging**.

## Prerequisites
- Connect your Xiaomi device to a Wi-Fi network.
- Enable **Developer options** (tap *OS Version* 7 times in *About phone*).

## Setup Steps


### Install Shizuku
Install [Shizuku from Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api) or GitHub.

### Enable Wireless Debugging
Go to **Developer options** > Enable **USB debugging (Security settings)** and **Wireless debugging**.

### Pair Shizuku
In Shizuku, tap **Pairing**, then enter the 6-digit Wi-Fi pairing code displayed in the developer options notification.

### Start Shizuku
Return to the Shizuku app and tap **Start**. Once running, grant HyperBridge access under **Authorized applications**.
