## Flujo de Trabajo con Pull Requests

1. Haz un Fork del repositorio en GitHub: [HyperBridge](https://github.com/D4vidDf/HyperBridge).
2. Crea una rama para tu función o corrección (`git checkout -b feature/nueva-mejora`).
3. Sigue las convenciones de commit de Conventional Commits (`feat:`, `fix:`, `docs:`).
4. Verifica que las pruebas compilen y envía tu Pull Request en GitHub.
