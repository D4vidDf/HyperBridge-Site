Learn about system requirements and how to install Hyper Bridge on your device.

## System Requirements

- **Operating System:** Xiaomi HyperOS 3.0 or Xiaomi HyperOS 4.0 (Android 15 / Android 16 / Android 17).
- **Supported ROMs:** Global, EEA, India, Taiwan, and CN (China) ROMs (CN ROMs require Shizuku or Sui for the Xiaomi bypass).
- **Root:** **Not required!** Hyper Bridge operates without root access.

---

## Download & Installation

You can install Hyper Bridge from the Google Play Store or download the APK directly from GitHub Releases.

### Option 1: Google Play Store (Recommended)

Get Hyper Bridge directly from the Google Play Store for verified downloads and automatic background updates:

- **Download on Google Play:** [Hyper Bridge on Google Play Store](https://play.google.com/store/apps/details?id=com.d4viddf.hyperbridge)

### Option 2: GitHub Releases (Direct APK)

1. Visit the official [GitHub Releases](https://github.com/D4vidDf/HyperBridge/releases) page.
2. Download the latest `HyperBridge-vX.X.X.apk`.
3. Open the downloaded file on your Xiaomi device and grant installation permission to your package installer.
